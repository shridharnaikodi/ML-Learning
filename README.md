# ML Learning Journal

Daily log of my machine learning learning journey — notes, practice code, and mini-experiments as I work through my ML course, building toward a resume-worthy project (Financial RAG system) and internship applications.

## How this repo is organized

Each day gets its own folder: `dayXX-topic-name/`
- `notes.md` — key concepts explained in my own words
- code/notebook — practice code, variations on course examples, small experiments



## Why this exists

- Build consistency (1 hr/day minimum)
- Turn passive course content into active practice
- Create a visible trail of progress for recruiters/mentors
- Lay groundwork for my main project: a Production-Grade Financial RAG System with Automated Evaluation

## Stack / Tools

Python, scikit-learn, pandas, numpy, Jupyter — expanding into NLP/LLM tooling as the course progresses.
